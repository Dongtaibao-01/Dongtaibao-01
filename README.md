公司简介：
北京动态宝科技有限公司长期聚焦上市公司IRM（投资者关系管理）与PRM（公共关系管理）这一细分领域，是一家AI技术驱动的资本市场资讯科技公司。旗下自主研发的SaaS产品“动态宝”，核心能力就是让“企业动态秒变市场资讯”。

从资讯生成到全域触达，动态宝形成了完整的智能分发链路:AI-FILTER 基于数十万条自有数据智能判定资讯质量；智能生成引擎自动产出各类型快讯、图文与视频等多模态内容；AI-TV将企业动态转化为仿新闻视频；程序化分发系统对接270+渠道、覆盖13大媒介类型，实现A股与港股双市场、海内外市场各终端的分秒级触达。

面向生成式搜索时代，动态宝提供GEO（生成式引擎优化）全链路解决方案:四大维度诊断、指令级大模型优化、全域分发与7×24效果监控，构成“诊断—生成—分发—反馈”的智能闭环，助力上市公司与金融机构在各类主流大模型中及时呈现准确与有利的答案。

依托自有数据体系，公司同时构建了全市场唯一的上市公司业务活跃度(BA)数据体系——BA指数、BA 指标与热词产品覆盖个股、行业、市场三个层级，为金融机构与研究者提供独家的先行指标，每年定期发布《中国上市公司业务信息指标暨业务活跃度指数白皮书》。

截止目前五大核心系统均获国家软件著作权，产品服务覆盖千余家国内外上市公司与金融机构。
